# FocusDesk

Настольный планировщик учёбы и работы для Windows. Проекты, задачи, доска статусов, таймер концентрации и статистика. Работает локально без аккаунта и сервера.

![Экран с примерами задач](docs/screenshots/today.png)

## Запуск

Нужны Windows и .NET 10 SDK. Из этой папки:

```powershell
dotnet run --project src/FocusDesk.App -c Release
```

Либо откройте `FocusDesk.slnx` в Visual Studio с компонентами разработки классических приложений .NET.
`Start.cmd` собирает приложение при первом запуске. Готовая сборка и пользовательская база в Git не хранятся.

## Что реализовано

- Проекты: создание, переименование, выбор цвета из палитры.
- Задачи: название, описание, проект, приоритет, срок, статусы «Запланировано», «В работе», «Готово».
- Поиск по названию и описанию; фильтрация по проекту и статусу.
- Доска с перемещением задач кнопками и редактированием карточек.
- Архивирование и восстановление задач. Без необратимого удаления.
- Обзор дня: текущие задачи, сроки, время концентрации и завершённые задачи.
- Таймер на 15, 25, 45 или 60 минут, привязка к задаче или свободная сессия.
- Пауза, продолжение и досрочное завершение с сохранением фактического времени.
- История сессий и график концентрации за последние семь дней.
- Создание и восстановление резервных копий в разделе «Настройки».

При закрытии приложения текущая сессия сохраняется на паузе и доступна после запуска. Пока таймер работает, контрольная точка сохраняется каждые пять секунд. При аварийном завершении возможна потеря последних секунд с момента последней успешной записи. При обычном закрытии сохраняется текущий прогресс. При уведомлении Windows о переходе в сон приложение ставит таймер на паузу.

Таймер использует монотонный Stopwatch. Паузы исключаются; задержка обработки события не увеличивает сессию сверх выбранной длительности. В статистике время относится к локальному дню завершения сессии. Завершение таймера само по себе не помечает задачу готовой.

## Данные и резервные копии

При запуске из этого проекта база находится в `Data/focusdesk.db`. Полный путь виден в настройках. При переносе папки `app` отдельно база создаётся в её подпапке `Data`; папка должна быть доступна для записи.

Для восстановления выберите файл копии и подтвердите замену. До замены текущая база автоматически сохраняется в `Data/Backups`. Копия проверяется перед применением; незавершённый таймер из копии не возобновляется. Перед восстановлением нужно завершить текущую сессию.

База не зашифрована. Доступ к файлу определяется правами Windows. Синхронизации с облаком нет. Папки с данными и сборками исключены из Git. Храните резервную копию также на другом носителе.

## Архитектура

- `src/FocusDesk.Core/Models.cs` — модели данных и независимо проверяемые правила таймера.
- `src/FocusDesk.Core/DeskStore.cs` — SQLite, валидация, операции с задачами и резервными копиями.
- `src/FocusDesk.App/` — WPF: ресурсы оформления, окно приложения и формы редактирования.
- `tests/FocusDesk.Tests/` — автономные проверки логики на отдельной временной базе.

Интерфейс использует обработчики событий в code-behind; хранение данных и расчёт времени отделены от WPF. Это небольшая слоистая архитектура, без внешнего MVVM-фреймворка. Единственная прямая зависимость — Microsoft.Data.Sqlite 10.0.12; NuGet загружает её зависимости автоматически.

Связи: `projects` → `tasks` → `sessions`. История хранит название задачи на момент начала сессии, поэтому переименование задачи не переписывает прошлое. `timer_draft` хранит единственную незавершённую сессию. UUID сессии предотвращает повторное добавление при повторной записи. Сохранение сессии и удаление контрольной точки происходят в одной транзакции.

## Сборка и проверки

Из каталога проекта в PowerShell:

```powershell
dotnet build FocusDesk.slnx -c Release
dotnet run --project tests/FocusDesk.Tests -c Release
dotnet publish src/FocusDesk.App -c Release -o app
```

Или используйте `Test.cmd` для проверок.

27 проверок охватывают валидацию, сохранение после переподключения, статусы, архив, паузу и продолжение таймера, ограничение длительности, контрольные точки, отсутствие повторных сессий, резервное копирование и отказ от повреждённой копии.

Встроенная проверка интерфейса отрисовывает семь реальных WPF-экранов и проверяет обработчики кнопок таймера на отдельной базе:

```powershell
$env:FOCUSDESK_DATA = "$PWD\artifacts\ui-test-data"
dotnet src/FocusDesk.App/bin/Release/net10.0-windows/FocusDesk.dll --verify-ui "$PWD\docs\screenshots"
Remove-Item Env:FOCUSDESK_DATA
```

Для этого режима обязательно задаётся отдельная папка данных. Он добавляет примеры и короткую тестовую сессию. Полученные изображения показывают реальные WPF-компоненты, отрисованные вне экрана. Проверка не заменяет ручную проверку окна с мышью, экранным диктором и разными масштабами Windows.

## Для демонстрации на собеседовании

1. Создайте проект и задачу, назначьте срок и приоритет.
2. Найдите задачу фильтром, переведите её в работу на доске.
3. Запустите фокус, поставьте на паузу и завершите сессию.
4. Покажите статистику и сохранение данных после перезапуска.
5. Создайте резервную копию и объясните безопасность восстановления.
6. Покажите тесты таймера без реального ожидания и транзакцию сохранения сессии.

Первая версия не включает облачную синхронизацию, повторяющиеся задачи, перетаскивание карточек, системные напоминания о сроках или фоновую работу после закрытия окна. Их можно добавить отдельными следующими этапами.

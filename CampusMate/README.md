# CampusMate

[← Все проекты](../README.md) · [Инструкция запуска](../docs/QUICKSTART.md)

![Демонстрационный экран](docs/preview.png)

Перед запуском установите Node.js 24 и pnpm 11, затем выполните `pnpm install --frozen-lockfile` в этой папке.
Мобильное приложение для личного учебного плана: предметы, недельное расписание, задания, дедлайны и средневзвешенные оценки. React Native + Expo SDK 54 + TypeScript.

## На компьютере
Start-Web.cmd собирает и запускает браузерную версию. Открой адрес Computer, который появится в окне. Адрес Phone предназначен для iPhone в той же локальной сети. Сервер должен оставаться запущенным.
Start-Expo.cmd запускает проект для Expo Go на порту 8081.

## На iPhone с Expo Go
1. Установи совместимую с Expo SDK 54 версию Expo Go. Если версия из App Store уже не поддерживает SDK 54, используй web-версию или обнови Expo и зависимости.
2. Войди в Expo Go в свой аккаунт Expo.
3. Один раз запусти Expo-Login.cmd и войди в тот же аккаунт. Пароль вводи самостоятельно в терминале.
4. Подключи компьютер и телефон к одной сети. Запусти Start-Expo.cmd.
5. Отсканируй QR-код камерой iPhone. Окно сервера на компьютере оставь открытым.
6. Если Windows спросит о доступе к локальной сети, разреши его для своей частной сети.
При сетевой изоляции можно попробовать expo start --tunnel; этот режим потребует дополнительного подключения через ngrok.

Expo Go — тестовый контейнер, а не самостоятельная установленная сборка. Для постоянной нативной установки и TestFlight нужны подписанная сборка и учётная запись Apple Developer. eas.json подготовлен, облачная сборка ещё не запускалась.

## Для повседневного использования и друзей
После `pnpm export:web` в dist появится браузерная версия с manifest и service worker. Для независимой от твоего компьютера ссылки размести dist на статическом HTTPS-хостинге. Затем на iPhone: Safari → Поделиться → На экран «Домой» → Открывать как веб-приложение.
Offline-кэш работает после первого полного открытия через HTTPS; localhost также допускается браузером. На локальном HTTP-адресе компьютера на iPhone offline-кэш не работает.
У каждого друга свои данные на своём устройстве. Не передавай друзьям пароль от Expo. Для общего расписания экспортируй текстовый файл в разделе «Расписание».
Данные Expo Go и Safari раздельные: переноси их JSON-экспортом/импортом.

## Данные
Старт без примеров либо явно помеченный демо-режим. Это не реальное расписание AITU.
AsyncStorage: локальное, незашифрованное хранилище. Нет серверной синхронизации, подключения к университету и фоновых уведомлений.
При записи сохраняется предыдущая корректная версия. Повреждённое основное сохранение загружается из backup. Если обе копии повреждены, приложение не перезаписывает их без явного сброса.
Настройки → экспорт JSON сохраняет предметы, расписание, задания и оценки. Импорт проверяет формат и запрашивает подтверждение замены. Удаление предмета также удаляет его связанные записи.
Средняя оценка = сумма (балл / максимум × 100 × вес) / сумма весов. Это не официальный GPA.
Удаление приложения, очистка браузера или удаление данных Expo Go могут удалить записи: периодически экспортируй копию.

## Разработка
Node.js 20.19+; pnpm.
pnpm install --frozen-lockfile
pnpm start
pnpm typecheck
pnpm test
pnpm exec expo export --platform web
node tools/prepare-web.mjs

App.tsx — экраны и формы; src/domain.mjs — проверка данных и расчёты; src/storage.ts — хранение/экспорт; src/ui.tsx — компоненты интерфейса; tests — проверки логики.
Иконки в assets. Нативные iOS/Android JS/Hermes-bundles проверяются expo export --platform all; это не подписанный IPA/APK.

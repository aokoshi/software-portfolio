# HikkiAnime

Каталог из 600 аниме и просмотр подключённых официальных выпусков. Интерфейс на русском: поиск, жанры, год, формат, сортировка, страницы каталога, карточки тайтлов и переключение серий. HTML, CSS и JavaScript без внешних JS-зависимостей и этапа сборки.

## Запуск

Нужен Node.js 24+:

```sh
node server.mjs
```

Откройте адрес из терминала. Не открывайте HTML двойным щелчком: браузер должен получить JSON через HTTP. `Start.cmd` запускает сервер на Windows.

## Что доступно для просмотра

**«Тупой меч» / Namakura Gatana (1917)** — полный фильм через HTML5 video с Wikimedia Commons. Фильм отмечен источником как public domain; музыкальное сопровождение «Ishikari Lore» — Kevin MacLeod, CC BY 3.0. Авторство, ссылка на оригинал, музыку и лицензию показаны рядом с плеером. Версия с музыкой опубликована участником Di (they-them), без изменений с нашей стороны. Источник и воспроизводимый импорт: `tools/import-classic.mjs`; атрибуция сохранена в `dist/data/classic.json`.

Семь эпизодов **Pokémon: Twilight Wings / Сумеречные крылья**, на английском, с The Official Pokémon YouTube channel. YouTube oEmbed подтвердил названия и издателя при импорте. Видео встраивается через youtube-nocookie.com, не скачивается и не хранится на нашем сервере. Географические ограничения, возрастные ограничения, реклама, качество и субтитры определяются издателем и YouTube. Для отказа встроенного плеера есть ссылка на исходный выпуск.

Для остальных тайтлов доступна карточка каталога, явно помеченная отсутствием подключённых серий. Источник AniDub **не подключён**: подтверждённая публичная документация о разрешённом встраивании в ходе исследования не найдена. Наличие открытой страницы с видео само по себе не является документацией API.

## Данные и лицензия

Используется [anime-offline-database](https://github.com/manami-project/anime-offline-database), выпуск **2026-27**, обновление **2026-07-04**. Репозиторий источника архивирован. Это снимок данных, не текущий календарь релизов. Извлечение и преобразование полей выполнены `tools/import-catalog.mjs`; исходный URL, дата и список изменений сохранены в JSON.

`dist/data/catalog.json` — производная выборка: ODbL 1.0 + DbCL 1.0, как исходная база. Полный текст находится в `dist/data/LICENSE-ODbL.txt`; на сайте есть атрибуция и ссылка для скачивания базы. Русские названия и короткие описания в `domain.mjs` написаны для интерфейса отдельно. Рейтинг — округлённое среднее по доступным поставщикам, не исключительно рейтинг MyAnimeList.

Обложки загружаются по внешним URL из базы. Медиа не объявляются общественным достоянием или собственностью HikkiAnime. Лицензия базы не передаёт автоматически права на обложки и видео.

[Jikan](https://jikan.moe/) также проверен как возможный API, но во время разработки вернул 504 при обращении к MyAnimeList. Текущий каталог не зависит от его доступности. Аккаунтов, синхронизации, платежей, загрузки видео на сервер и пользовательских iframe в этой версии нет.

## Структура

- `dist/index.html`, `style.css` — оболочка и адаптивное оформление.
- `dist/app.js` — hash-маршруты, поиск, фильтры, страницы тайтлов и плеер.
- `dist/domain.mjs` — чистые функции поиска, проверка URL и перевод подписей.
- `dist/data/catalog.json` — 600 записей с источниками и лицензией.
- `dist/data/episodes.json` — реестр семи официальных YouTube-выпусков и классического фильма.
- `tools/import-catalog.mjs` — воспроизводимый импорт закреплённого выпуска базы; нужен Node.js 24 с Zstandard.
- `tools/import-episodes.mjs` — проверка названий и издателя через YouTube oEmbed.
- `tests/catalog.test.mjs` — поиск, фильтры, идентификаторы эпизодов и безопасные URL.

## Проверка и обновление

```sh
node --check dist/app.js
node --test tests/catalog.test.mjs
```

Обновление данных (с доступом в интернет): `node tools/import-catalog.mjs` и `node tools/import-episodes.mjs`. При добавлении провайдера сначала зафиксируйте условия интеграции и источник, затем расширьте разрешённые хосты, реестр и проверки. Не принимайте произвольный HTML или URL iframe от посетителей.

Для обновления классического фильма отдельно выполните `node tools/import-classic.mjs`. Обновление YouTube-реестра сохраняет подключённый классический фильм.

## Результат проверки

Поиск по русскому названию, совмещение фильтров, пустая выдача и просмотр классического фильма проверены в браузере. HTML5-плеер загрузил видео длительностью 257,872 секунды и воспроизвёл первые секунды без ошибки. Первый YouTube-выпуск во встроенном браузере ответил «Видео недоступно»; доступность всех семи выпусков у конкретного зрителя не гарантируется, хотя их метаданные подтверждены официальным каналом. Это ограничение внешнего провайдера не скрывается за демонстрационным видео.

Для статического хостинга публикуется содержимое `dist/`, включая JSON, лицензию и `_headers`. Маршруты после `#` работают без серверного роутера. Поиск поддерживает названия и синонимы из базы; не все 600 названий имеют русский перевод. При недоступности обложки показывается знак HikkiAnime.

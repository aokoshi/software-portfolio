# PocketBudget

[← Все проекты](../README.md) · [Инструкция запуска](../docs/QUICKSTART.md)

![Демонстрационный экран](docs/preview.png)

Перед запуском установите Node.js 24 и pnpm 11, затем выполните `pnpm install --frozen-lockfile` в этой папке.
Личный журнал доходов и расходов в KZT: категории, поиск, итог месяца, лимиты расходов, цели накопления, JSON-копии и CSV-экспорт. React Native + Expo SDK 54 + TypeScript.

## Запуск
Start-Web.cmd — сборка и запуск браузерной версии (порт 8092). В терминале будут адреса для компьютера и телефона в той же сети.
Start-Expo.cmd — запуск в Expo Go (порт 8082).
Expo-Login.cmd — вход в аккаунт Expo на компьютере. В Expo Go на iPhone должен быть тот же аккаунт.
После запуска Start-Expo.cmd сканируй QR-код камерой iPhone. Компьютер и телефон подключи к одной сети, сервер оставь работать. Если Windows спросит о доступе, разреши его для своей частной сети.

Проект закреплён на Expo SDK 54. Для нативного запуска нужна совместимая версия Expo Go; при несовпадении SDK используйте web-версию или обновите Expo и зависимости. Это среда тестирования; самостоятельный iOS-пакет и TestFlight потребуют подписи и Apple Developer. eas.json подготовлен, платная сборка не запускалась.

## Поделиться с друзьями
Для ссылки, которая работает без твоего компьютера, после `pnpm export:web` папку dist можно разместить на статическом HTTPS-хостинге. Друзья откроют её в Safari и добавят на экран «Домой». Manifest и offline service worker подготовлены.
Кэширование доступно после первого полного открытия по HTTPS или localhost. На HTTP-адресе локальной сети в iPhone offline-режим недоступен.
У каждого пользователя собственные локальные записи. Пароль от Expo друзьям передавать не нужно. Синхронизации, общих кошельков и подключения банков нет.

## Как считаются суммы
Внутри используются целые тиыны: 0,01 ₸ = 1. Отрицательные, нулевые и неоднозначные суммы отклоняются.
Итог месяца — доходы минус расходы за выбранный месяц, а не остаток на реальном банковском счёте.
Лимит относится к конкретному месяцу и категории. Превышение отображается отдельно. Накопления в целях отмечаются вручную и не вычитаются автоматически из операций.
В CSV включены все операции. Строки экранированы, формульные префиксы комментариев обезврежены.
Демо-данные помечены; для своих финансов выбери пустой старт или очисти демо в настройках.

## Хранение и резервные копии
AsyncStorage — незашифрованное локальное хранилище. Серверу ничего не передаётся. Не записывай сюда пароли, реквизиты карт или банковские токены.
Сохраняется предыдущая корректная версия. При повреждении основной записи приложение пытается восстановить её. Если восстановление невозможно, данные не заменяются молча.
JSON-экспорт содержит твои финансовые записи. Импорт проверяет формат и запрашивает подтверждение замены.
Данные Safari и Expo Go раздельные. Для переноса используй JSON-копию.
Очистка браузера, удаление приложения или сброс данных Expo Go могут удалить записи. Сохраняй копию отдельно.

## Разработка
Node.js 20.19+ и pnpm.
pnpm install --frozen-lockfile
pnpm start
pnpm typecheck
pnpm test
pnpm exec expo export --platform web
node tools/prepare-web.mjs

App.tsx — экраны; src/domain.mjs — суммы, категории, валидация, CSV; src/storage.ts — данные и экспорт; src/ui.tsx — интерфейс.
expo export --platform all проверяет JS/Hermes-bundles для iOS/Android и web. Это не выпуск подписанного IPA/APK.

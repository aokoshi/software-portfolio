# Сайт «Светолесье»

[← Все проекты](../README.md)

Лендинг 2D RPG: три локации, карточки существ с эволюциями, музыкальный проигрыватель и адаптивная сетка. HTML, CSS и JavaScript без внешних библиотек.

![Главная страница](docs/preview.png)

## Запуск

```sh
node server.mjs
```

Откройте адрес из терминала. `dist/` здесь содержит **исходники сайта**, поэтому включён в Git.
`node check.mjs` проверяет локальные ссылки и ресурсы. Шрифты загружаются из Google Fonts; без сети используются системные шрифты.

## Структура

- `dist/index.html` — содержание.
- `dist/style.css` — оформление и адаптивность.
- `dist/app.js` — переключение локаций, эволюций и музыкальных тем.
- `dist/assets/` — рисунки, скриншоты и WAV, созданные для игры.
- `tools/ExportArt/` — экспорт иллюстраций из соседнего проекта игры; требует Windows и .NET 10 SDK.

В версии для репозитория кнопка ведёт к [исходникам и инструкции игры](../Svetolesye). Исполняемый ZIP и настройки частного хостинга в Git не включены. Сайт можно разместить на статическом хостинге отдельно.

# Светолесье — путешествие трёх земель

Небольшая 2D RPG для Windows на C# / .NET 10 / WPF. Исследование клеточных карт, пошаговые бои, приручение существ, развитие команды и локальные сохранения. Персонажи, пиксельные рисунки и синтезированные мелодии созданы для этого проекта.

## Запуск
Нужны Windows и .NET 10 SDK. Откройте `Start.cmd` для сборки и запуска либо выполните:

```powershell
dotnet run --project src/Svetolesye.Game -c Release
```

Решение для Visual Studio: `Svetolesye.slnx`. Для запуска опубликованной сборки достаточно .NET Desktop Runtime 10. Сборки и сохранения не включены в Git.

## Три главы
1. Тихая роща: соберите три разных семейства и победите Ветрокрона. Восточная арка в конце нижней дороги ведёт к берегу.
2. Зеркальный берег: зажгите три маяка, победите Приливня. Северо-восточная арка открывает перевал.
3. Лунный перевал: пройдите испытания стражей ветра и камня, затем победите Астрарона.

В каждой земле свои места встреч, целитель, оформление, музыка и звуки природы.

## Опыт и эволюция
За победу и приручение начисляется XP. Участники боя получают полную награду, запасные — половину. Для потерявших сознание награда дополнительно уменьшается вдвое. Только что приручённое существо не получает XP за собственную поимку.

На 8 уровне в меню команды появляется кнопка «Эволюция». Доступны пять цепочек:
- Мшун → Мохорог
- Искрик → Жаролис
- Каплик → Акварин
- Крошень → Гранитыш
- Лунница → Лунокрыл

Уровень и накопленный опыт сохраняются, характеристики растут. Максимальный уровень — 30. Эволюции одного вида считаются одним семейством для первого испытания.

## Управление
WASD / стрелки — движение; Shift — быстрый шаг; E / Enter / Space — действие или продолжение.
C — команда; Tab — дневник; стрелки в дневнике — страницы; F5 — сохранение; Esc — помощь / назад.
В бою кнопки 1–6 выбирают действия. Меню работают мышью.
M отключает или включает звук. Кнопка «Звук» на карте и настройки в помощи позволяют отдельно менять музыку, эмбиент и эффекты. При переключении на другое окно звук приостанавливается.

## Звук
Пять зацикленных музыкальных тем, три звуковых окружения и 17 коротких эффектов. Генератор tools/AudioForge создаёт стерео PCM WAV 22050 Гц без внешних библиотек и сетевых сервисов. Настройки громкости находятся в Data/audio-settings.json.

Перегенерация из корня проекта:
```powershell
dotnet run --project tools/AudioForge -- src/Svetolesye.Game/Assets/Audio
```

## Сохранения
Data/journey.json — основное сохранение; .bak — предыдущая корректная версия.
Сохранение v1 автоматически переносится при продолжении игры. Перед первой записью v2 оригинал сохраняется в journey.json.v1.bak. Не удаляйте папку Data при обновлении.
При выходе во время боя сохраняется состояние перед встречей.

## Архитектура
- src/Svetolesye.Core — карты, существа, XP, эволюция, бои, задания, сохранения.
- src/Svetolesye.Game — WPF отрисовка, ввод, анимации и многослойный звук.
- tests/Svetolesye.Tests — автономные проверки логики и WAV.
- tools/AudioForge — воспроизводимый генератор музыкальных и звуковых файлов.
- docs/screenshots-v2 — 17 реальных кадров WPF, созданных вне экрана с отдельным тестовым сохранением.

## Проверки и сборка
```powershell
dotnet run --project tests/Svetolesye.Tests
dotnet publish src/Svetolesye.Game -c Release -o app
```

Проверены достижимость жителей и переходов, условия открытия глав, победы над новыми хранителями, XP, эволюция, миграция и резервное копирование, восстановление повреждённого сохранения, параметры звука и отсутствие цифрового клиппинга в WAV.
Все 25 звуковых файлов дополнительно успешно открыты Windows MediaPlayer. Это проверка декодирования; субъективное прослушивание на пользовательских колонках не выполнялось.

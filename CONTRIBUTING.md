# Работа с репозиторием

Проекты независимы. Откройте нужную папку, прочитайте её README и установите только необходимые для неё инструменты. Общие инструкции: [QUICKSTART](docs/QUICKSTART.md).

Для изменения создайте ветку, внесите правку и выполните относящиеся к проекту [проверки](docs/VERIFICATION.md). В pull request опишите задачу, новое поведение и способ проверки. Для изменений интерфейса приложите скриншот с демонстрационными данными.

Не добавляйте в коммиты рабочие базы, пароли, `.env`, `config.local.php`, пользовательские экспорты, сохранения, `node_modules` и результаты сборки. Исходные файлы сайтов в `delo-services/dist` и `Svetolesye-site/dist` должны оставаться в Git; `dist` мобильных приложений генерируется заново.

Если меняются команды запуска, зависимости или ограничения, обновите README проекта вместе с кодом.
